# Ouza Studio — site vitrine

Site statique : `index.html`, `assets/css/style.css`, `assets/js/main.js`. Ouvrir `index.html` dans un navigateur.
Polices via Google Fonts (Bricolage Grotesque, Instrument Sans, DM Mono).

## Direction : « Le plan de montage »
- Cadre + repères de coupe : Shopify (interface).
- Timecode : motion design.
- Fil vertical + nœuds : automatisation (déclencheur en cercle, actions en carrés).

## Médias
- `assets/video/hero.mp4`, `hero.webm`, `poster.jpg` : vidéo de démonstration (hero, scène, section motion).
- `assets/img/frame-1..4.jpg` : plans extraits de cette vidéo (planche-contact).
